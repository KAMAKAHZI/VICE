Internal engineering • 2026-10-16 UTC • 1.3.8.0-IRU-CERTIFICATES

Upload allowed files to Documents; metadata references a private Storage object and SHA-256 digest. Download uses authorized storage access. Preserve the original document and audit records.

The existing Sign action records typed name, consent and server-side evidence bound to the document digest. It is not a completed multi-signer request/sequence/reminder platform. No legal-compliance certification is asserted.

Edit form now supports AcroForm text/date text, checkboxes and dropdown/radio selections with PDF export and private new-copy saving. Profile autofill reads the current backend profile and fills only explicit matching identity/contact fields. Originals, read-only fields and signed documents are preserved; XFA and signature-field PDFs are refused. Three PDF save/reload tests pass. Authenticated storage-save acceptance remains unverified.

Arbitrary PDF text editing, linked version history, profile-driven template generation and completed signed-PDF composition remain incomplete. A full-content editor requires an appropriate licensed engine; signature-provider integration requires account configuration and webhook credentials. These are open implementation workstreams, not passed acceptance criteria.
