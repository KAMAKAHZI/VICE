# VICE OS / Document and Signature Guide

Internal engineering • 2026-10-15 UTC • 1.3.8.0-IRU-CERTIFICATES

Upload allowed files to Documents; metadata references a private Storage object and SHA-256 digest. Download uses authorized storage access. Preserve the original document and audit records.

The existing Sign action records typed name, consent and server-side evidence bound to the document digest. It is not a completed multi-signer request/sequence/reminder platform. No legal-compliance certification is asserted.

AcroForm editing, arbitrary PDF text editing, editable version retention, profile-driven template generation and completed signed-PDF composition are not implemented by this repair. A full-content editor requires an appropriate licensed engine; signature-provider integration requires account configuration and webhook credentials. These are open implementation workstreams, not passed acceptance criteria.
