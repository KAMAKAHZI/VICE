# VICE OS / User Guide

Internal engineering • 2026-10-15 UTC • 1.3.8.0-IRU-CERTIFICATES

Sign in using email or username and password. Google sign-in requires configured provider credentials. Existing members should not need to redeem invitations again. Use Forgot password to request the recovery email. A temporary profile error preserves the Supabase session; retry when connectivity returns.

The sidebar opens existing modules. Account → Run Diagnostics checks public endpoints and authorized reads. Diagnostics are connectivity checks, not proof of financial correctness.

Communications provides channels and direct messages. Failed writes display an error and retain the draft. History currently loads the most recent 200 messages; older-history pagination, server read receipts, editing and search are not completed. Images and voice notes use private storage. Calls currently provide one-to-one audio. Video, screen sharing and group conferencing are not available.

Charts use provider candles or explicitly selected imports/practice data. Yahoo requests use the same-origin function. No valid data produces an unavailable state. Do not treat provider-dependent timing as guaranteed real time.

Documents supports upload/download and a server-recorded typed-name attestation. This is not a full PDF editor or enterprise signing-request service. Academy quiz and certificate authority is server-side; chapter reading marks remain device-local and account-scoped.

Sign out explicitly before sharing the device. Successful logout clears member collections and closes media resources. Failed signout reports failure and preserves the active session.
