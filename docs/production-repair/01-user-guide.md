# VICE4X / User Guide

Internal engineering • 2026-10-16 UTC • 1.3.8.0-IRU-CERTIFICATES

Sign in using email or username and password. Google sign-in requires configured provider credentials. Existing members should not need to redeem invitations again. Use Forgot password to request the recovery email. A temporary profile error preserves the Supabase session; retry when connectivity returns.

The sidebar opens existing modules. Account → Run Diagnostics checks public endpoints and authorized reads. Diagnostics are connectivity checks, not proof of financial correctness.

Communications provides channels and direct messages. Failed writes display an error and retain the draft. History currently loads the most recent 200 messages; older-history pagination, server read receipts, editing and search are not completed. Images and voice notes use private storage. Calls provide audio with camera/screen-sharing controls after a connection is established. Camera and screen sharing are implemented for one-to-one calls; cross-network verification remains open. Group SFU conferencing remains unavailable.

Charts use provider candles or explicitly selected imports/practice data. Yahoo requests use the same-origin function. A failed live feed clears the chart and shows an unavailable state. Do not treat provider-dependent timing as guaranteed real time. Drag the chart to pan time and price, drag the right price axis to scale prices, and use the wheel or two-finger pinch to zoom. Reset view restores automatic scaling. See the Trading and SOLACE Guide for keyboard controls.

Documents supports upload/download, PDF form editing and a server-recorded typed-name attestation. Edit form supports compatible AcroForm fields, profile autofill, export and saving a new private copy. It does not edit arbitrary PDF page text or provide a complete signing-request service.

In Academy, open a chapter and select Mark read. In live mode the completion check appears only after the database confirms the receipt. A failed request leaves the chapter unmarked so it can be retried. Prior device-only marks must be reconfirmed to become backend receipts. Complete the 21 core chapters and pass all seven core assessments at 75% or above before requesting a new completion certificate. The server checks the verified profile name, canonical course title and recorded results; repeated eligible requests return the existing active certificate. Previously issued legitimate certificates are preserved.

Sign out explicitly before sharing the device. Successful logout clears member collections and closes media resources. Failed signout reports failure and preserves the active session.
