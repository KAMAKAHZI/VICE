# VICE4X / Portfolio valuation disclosure

Copy update • 2026-10-17 UTC • release 1.3.8.0-IRU-CERTIFICATES

The Dashboard and Portfolio now explain their management reference basis and intended collateral use in a short visible note. An accessible native disclosure contains the supporting valuation and collateral terms. SIM mode is explicitly described as demonstration data. The founder view uses Estate/Admin Reserve terminology; recorded reserves remain institutional records. The related IRU help entry explains reference rates and transfer restrictions.

Visible LIVE wording:

> IRUs are displayed at VICE management reference values, alongside eligible verified linked account equity. Intended collateral use is subject to lender approval, independent valuation and executed agreements.

The disclosure does not assign a securities/non-securities classification or claim lender acceptance, an appraisal, cash availability or a credit commitment. It does not change valuation rates, calculations, allocations, reserve records, permissions or verified-account eligibility.
